# Unified Geo-Aware Land Management Portal

**SIH 2026 | Problem Statement SIH26016**

*One Map | One System | Transparent Land Governance*

## Tech Stack
- Frontend: React + Vite + Material UI
- Backend: Node.js + Express
- Database: PostgreSQL + PostGIS
- Deployment: Docker Compose

## Setup Instructions
1. Clone this repository.
2. Ensure you have Docker and Docker Compose installed.
3. Run `docker-compose up --build -d` from the root directory.
4. The system will be available at:
   - Frontend: `http://localhost:5173`
   - Backend API: `http://localhost:5000`
   - Database: `localhost:5432`
